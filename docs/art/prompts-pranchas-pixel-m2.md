# Pranchas e retratos do M2 em pixel art: prompts de conversão

Pedido de Alan (17/11/2026, D-424): ele mesmo gera, a partir das pranchas que já tem, e precisa do prompt completo de cada uma. O **conteúdo** de cada imagem vem dos prompts aprovados (`docs/narrative/prologue.md` §5 e `docs/art/art-direction.md` §11); o **estilo** vem de `docs/fable/prompts-pixel-m2.md` §2.7 e §10. Gerado por script a partir desses arquivos: se um deles mudar, refazer esta lista.

## Como usar

1. No Meta AI, **anexe a prancha antiga** (a de tinta) como imagem de referência e cole o prompt dela. O começo do prompt pede para manter composição, rostos e cores e trocar só o desenho para pixel.
2. Se a ferramenta não aceitar imagem, use o mesmo prompt sem anexo: o conteúdo inteiro da cena está no texto.
3. Pranchas em 16:9, retratos em 3:4. Depois eu converto para a grade do jogo (como nos cenários) e recorto o fundo cinza dos retratos.
4. Confira em cada imagem: um só tamanho de pixel; nenhuma letra; ouro só em auréola e na prancha de Nossa Senhora; santos e figuras sagradas com rosto sereno, nunca grotesco; terço de baixo mais escuro (menos a `P15`, que tem o céu vazio para o título).
