# Ad-Inferos---RPG
Repositório de desenvolvimento do game Ad Inferos

## Estrutura

- `game/` — projeto Godot 4.7 (abrir `game/project.godot`)
- `docs/` — GDD e Direção de Arte
- `architecture.md` — árvore de pastas e princípios de código
- `CLAUDE.md` — comandos (testes, importação) e convenções

Requer Git LFS (`git lfs install`) para os assets de arte e áudio.
